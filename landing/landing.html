POWER USERS & DEVELOPERS

Prefer running directly from source?

Clone repo, set up virtual environment, and launch the Electron frontend with Python coworker in seconds.

# Clone and launch Astra in 2 minutes
git clone https://github.com/PhongTran-code/Astra_AI.git
cd Astra_AI && python3 -m venv .venv
source .venv/bin/activate && pip install -e .
python -m coworker.server

07 / frequently asked questions

Clear answers to critical questions.

Everything you need to know about security, architecture, data locality, and pricing.

Everything stays on your physical device. Astra is built local-first: your workspace code, conversation history, connector credentials, and tool executions run locally. API keys are stored in your operating system's native credential keychain. If you use Ollama, zero network packets leave your computer.
Yes. Astra is 100% open source. There are no paid tier subscriptions, artificial feature gates, or hidden telemetry. You can run from source right now using your own provider keys or local open-weights models with zero expense.
Unlike conventional AI agents that rely on prompt-based instructions, Astra enforces architectural Hard Floors directly in the backend runtime. Irreversible actions (filesystem writes, external webhook triggers, package publishing) mechanically escalate to your human approval inbox, regardless of prompt tampering or autonomy level.
Yes. Astra includes 25+ verified connectors out-of-the-box and acts as a native host for the Model Context Protocol (MCP). Any MCP server exposing internal databases, proprietary APIs, or CLI tools can be integrated in seconds with fine-grained permission controls.
